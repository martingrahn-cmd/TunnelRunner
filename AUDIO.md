# Audio

Every sound in the game is generated by prompting the
[ElevenLabs Text-to-Sound-Effects API](https://elevenlabs.io/docs/api-reference/text-to-sound-effects/convert)
(`POST /v1/sound-generation`, model `eleven_text_to_sound_v2`). Nothing is
synthesised in the browser — Web Audio is used only as the mixer: pitch,
filtering, ducking and voice management.

## Generating the assets

```bash
ELEVENLABS_API_KEY=xi_... node tools/generate-sfx.mjs
```

Writes 16 mp3s to `assets/audio/` plus a `manifest.json` recording the exact
prompt behind each file.

| Flag | Effect |
| --- | --- |
| *(none)* | generates only what's missing |
| `--force` | re-rolls everything |
| `--only coin,impact` | re-rolls just those sounds |
| `--key xi_...` | key on the command line instead of the environment |

The prompts live in the `SOUNDS` array at the top of `tools/generate-sfx.mjs`.
Sound design happens by editing a prompt there and re-rolling that one file:

```bash
node tools/generate-sfx.mjs --only impact --force
```

`prompt_influence` is the dial worth knowing: higher sticks closer to the
words, lower gives the model room to be musical. The three loops
(`engine_loop`, `wind_loop`, `music_loop`) use `loop: true` and a high
influence — low values let them drift and the seam becomes audible.

## The 16 sounds

**Beds** (looped, continuous) — `engine_loop`, `wind_loop`, `music_loop`
**Pickups** — `coin`, `mission_complete`, `level_up`
**Danger** — `near_miss`, `impact`, `debris`, `low_life`, `game_over`
**Speed** — `boost_start`, `boost_end`, `portal`
**Interface** — `ui_click`, `ui_buy`

## How they're mixed

`audio.js` handles playback. Worth knowing:

- **The engine is tied to real tunnel speed.** `setSpeed(mul)` maps the
  combined speed multiplier onto the engine's playback rate (0.85 → 1.48) and
  a lowpass cutoff (700 Hz → 7 kHz), so the ship audibly strains as levels get
  faster. Wind is near-silent at rest and dominates during a boost.
- **Coins climb a pentatonic ladder.** Consecutive pickups step up
  `COIN_LADDER` and reset after a 0.7 s gap, so a coin run plays as a riff
  instead of the same sample 60 times.
- **Near-miss whooshes pitch up with the streak**, so a long clean run keeps
  escalating.
- **Impacts duck the beds** briefly so the hit reads clearly.
- Buses: sources → (sfx | music | loop) → master → out. Per-sound level trim
  lives in `TRIM` in `audio.js`, so balance can be fixed without re-rolling.

Missing files are a silent no-op — the game runs fine before the assets have
been generated.

`M` toggles mute (persisted). Pause and tab-blur suspend the context.
